# TabWeave 日本語化の全文確認

中国語を基本の翻訳元とし、英語の意味と技術用語も照合して、日本語の掲載文を整えました。Plamo の生訳をそのまま採用せず、冗長な表現は短くし、誤訳や現行仕様との違いを修正しています。

[日本語 README](../../README.ja.md) · [事前7例の比較](../../TRANSLATION_REVIEW.ja.md)

## 掲載前に修正した主な問題

| 原文や生訳での問題 | 掲載文への反映 |
| --- | --- |
| 中日で「先にエクスポート」が「インポート」に反転 | インポート・復元の前にエクスポートする手順を明記 |
| 英日の「reconciliation」が「自動照合」などになる | 分類を見直し、ルールに合わないタブを未分類に戻す動作を説明 |
| 中国語の「同一规则」で複数行の範囲が曖昧 | 英語の one pattern を参照し、1つのパターン内のいずれかの行に一致する条件と説明 |
| 休止が「破棄してください」「解放する」になる | タブを閉じる操作と区別し、「休止してメモリを解放」と説明 |
| 中国語の「标签」が一部で「タグ」になる | 「タブ」に統一 |
| サイドパネルを「閉じると Popup に戻る」と誤訳 | 設定をオフにするとポップアップを使う、という切り替えを説明 |
| Snooze の繰り返しが「通知」と訳される | 指定時刻にタブを開き直す機能として説明 |
| 原文では AI への URL 送信が「初期設定でオフ」 | 実装の `sendUrls: true` と正規化を確認し、URL と取得可能な補足情報を送信すると説明 |
| ストア原文では「URL共有をオフにできる」 | 現在の設定画面にその切り替えはないため、日本語・英語とも修正 |
| 一般設定もルールの同期スイッチに従うように読める | ルールは同期設定に従い、一般設定は常に同期ストレージへ保存することを区別 |
| 中国語は URL 読み込み完了のみを説明 | フォークのタイトル変更時の再判定は現在の英語と実装に合わせて保持 |
| APIキーの区切りがカンマだけと書かれている | 実装に合わせカンマと改行の両方を説明 |
| 生訳に「フィールド」「モード」「プリファレンス」などが混在 | 「判定対象」「判定方法」「設定」に整理 |
| エラーの「キーが不足」「AIオーガナイズ」などが分かりにくい | APIキーの設定や「AI整理」の再実行など、必要な操作を案内 |

「未分類」「整理」「休止」「一時保管」「設定」を共通の用語として使います。モデル名、URL、パターン、コード、置換変数、利用者が書いた名前やプロンプトは翻訳しません。

## 中国語と利用者のデータ

保護対象の中国語資源、記録したハッシュ、元の中国語・英語併記の変更履歴は変更していません。新しい項目には日本語・英語を用意し、中国語では英語を表示します。

新しいエラー表示は TabWeave 自身の既知の文だけを翻訳します。外部の AI プロバイダーが返した詳細やモデル名は原文を維持します。英語・中国語モードでは、元のエラーメッセージを維持します。

初期ルールの名前と AI の初期プロンプトは、確認のうえ既存の日本語を維持しました。`defaults-en-ja` の `defaultRuleNames` フィールドは実際には固定のグループ名なので、ルール名の翻訳元には使用していません。
