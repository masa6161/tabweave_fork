# TabWeave

たくさん開いた Chrome のタブを、ルールに沿って整理する拡張機能です。ドメイン、URL、ページタイトル、正規表現でタブをグループ化し、ページが変わったときも分類を見直します。

[English](./README.md) · [upstream の中国語版](./README.zh-CN.md) · [変更履歴](./CHANGELOG.ja.md) · [プライバシーポリシー](./PRIVACY.ja.md)

このリポジトリは [TabWeave](https://github.com/zxpzdtom/tabweave) のフォークです。[Chrome ウェブストアの公開版](https://chromewebstore.google.com/detail/tabweave/pmfoefbiapldlpljfpjienjahdfmefej)は upstream の拡張機能です。このフォークは [Releases](https://github.com/masa6161/tabweave_fork/releases) のビルド済み ZIP を使えば、Node.js の導入やビルドなしで読み込めます。[インストール手順](./INSTALL.ja.md)と[フォーク版の変更履歴](./CHANGELOG.fork.md)を参照してください。ソースからビルドする手順は下記にあります。

## 主な機能

- **ルールによるグループ化**：ドメイン・URL・タイトルを、部分一致・完全一致・正規表現で判定。
- **複数条件と優先順位**：条件ごとに対象とパターンを指定し、ルールをドラッグして優先順位を変更。
- **サイドパネルとポップアップ**：グループの確認、展開・折りたたみ、タブを閉じる操作、手動グループ化。
- **設定画面**：ルールの追加・編集・複製・削除、検索・一括操作、インポート・エクスポート。
- **分類の見直し**：自動整理が有効な場合、ルールに合わなくなったタブを未分類に戻す。
- **ウィンドウごとの自動整理**：自動整理を個別に停止・再開。URL が変わらないタイトル変更にも対応。
- **コマンド検索**：開いているタブ、グループ、履歴、整理コマンドを検索。
- **タブの整理と休止**：重複タブを閉じ、使っていないタブを休止してメモリを解放。
- **AI 整理**：AI のグループ化案を確認してから適用。必要に応じて固定ルールとして保存。
- **タブの一時保管**：タブやグループをいったん閉じ、指定した時刻に開き直す。毎日の繰り返しにも対応。
- **スナップショット**：ウィンドウのタブとグループを保存し、新しいウィンドウに復元。
- **表示の設定**：ダーク・ライト・システム連動のテーマ、標準・コンパクトの表示密度、日本語・英語・中国語。
- **キーボード操作**：作業画面、タブ整理、重複削除、コマンド検索のショートカット。

## 画面の使い分け

- **サイドパネル**：ページを見ながら現在のウィンドウのタブを整理します。初期設定では、拡張アイコンを押すと開きます。
- **ポップアップ**：タブを手早く確認・整理します。設定の「サイドパネルで開く」をオフにすると使えます。
- **設定画面**：ルール、自動処理、AI、表示、ショートカットを設定します。
- **新しいタブ**：グループと未分類のタブ、一時保管したタブ、スナップショットを確認します。ダッシュボードを非表示にしても検索は使えます。

新しいタブのウェブ検索には Chrome の既定の検索エンジンを使います。バックグラウンドでは、タブの作成、読み込み完了、URL・タイトルの変更、ショートカットを処理します。

## 自動整理とウィンドウ別の停止

初期設定では「タブ作成時に整理」「ページ更新時に整理」はどちらもオフです。自動整理を使うには、設定画面で必要な項目を有効にしてください。

「タブ作成時に整理」は、読み込み完了を待たずに新しいタブを判定します。「ページ更新時に整理」は、読み込み完了や URL・タイトルの変更時にルールを再判定します。

作業画面の「このウィンドウを自動整理」は初期状態でオンです。オフにすると、そのウィンドウは自動のルール適用、ドメインによる分類、同名グループの統合、折りたたみの対象から外れます。別のウィンドウで起きた更新による走査でも、既存のグループと展開状態を維持します。手動の「整理」は引き続き使えます。

オンに戻すと、自動整理の設定が有効な場合は、そのウィンドウだけを整理します。別のウィンドウへ移動したタブは、移動先の設定に従います。

ウィンドウ別のオン・オフは Chrome のセッション内で保持します。バックグラウンド処理の再起動では保持されますが、ウィンドウを閉じると削除されます。Chrome の再起動や拡張機能の再読み込み・無効化・更新では初期状態に戻ります。

## 初期ルール

初回設定では次のルールを用意しています。設定画面から初期ルールに戻すこともできます。

| ルール | 対象の例 | グループ名 |
| --- | --- | --- |
| Chrome と拡張のページ | `chrome://settings/`、拡張の設定画面 | `Chrome` |
| GitHub の作業 | `github.com` | `Code` |
| ドキュメントと資料 | docs、documentation、guide、manual、文档、指南、ドキュメント、資料 | `Docs` |
| AI アシスタント | ChatGPT、Claude、Gemini、Perplexity、Poe、Kimi、Doubao | `AI` |
| デザインツール | Figma、Canva、Dribbble、Behance | `Design` |
| ノートとナレッジ管理 | Notion、Yuque、Feishu、Lark | `Notes` |
| メールと予定 | Gmail、Outlook、Google Calendar | `Mail` |
| 動画と配信 | YouTube、Bilibili、Netflix、Vimeo、Twitch、Douyin、Kuaishou、iQIYI、Youku | `Video` |
| 画像と静的ファイル | icon、img、image、upload、svg、png、jpg、webp | `Assets` |
| ローカル開発 | `localhost`、`127.0.0.1`、`0.0.0.0`、`::1` | `Local Dev` |

保存したルール一覧は利用者の設定として扱います。すべてのルールを削除して保存した場合も、再読み込み後に初期ルールを勝手に追加しません。

## ルールの書き方

ルールには、ルール名、グループ名、色、有効・無効、1 つ以上の条件を設定します。ルールは上から順に判定し、最初に一致した有効なルールがタブのグループを決めます。

条件では次の 3 項目を指定します。

| 項目 | 指定する内容 |
| --- | --- |
| 判定対象 | ドメイン（ホスト名）、完全な URL、ページタイトル |
| 判定方法 | 含む（部分一致）、完全一致、正規表現 |
| パターン | 判定する文字列や正規表現。複数行にすると、いずれかの行に一致すれば該当 |

同じルールに複数の条件がある場合も、いずれかの条件に一致すれば該当します。部分一致と正規表現では、大文字・小文字を区別しません。編集画面のプレビューに URL やタイトルを貼り付けると、一致するか確認できます。

「グループ化の最小タブ数」は、初期ルールと、未分類のタブをドメインで整理する処理に適用します。ルール側の最小タブ数が空欄の場合、初期ルールは共通設定を使い、独自ルールは 1 タブからグループ化します。

## インポートとエクスポート

設定画面の「設定をエクスポート」で、現在のルールと一般設定を JSON ファイルに保存します。「設定をインポート」で、そのファイルから復元できます。

インポートでは、確認後に現在のルールをすべて置き換え、ファイルに含まれる設定を適用します。後で元に戻す可能性がある場合は、**先に現在の設定をエクスポート**してください。

AI プロバイダーの設定や API キーは、このエクスポートには含まれません。

## AI による整理

設定で「AI 整理を有効にする」をオンにして、プロバイダーを選びます。クラウドの AI には API キーとモデルを設定し、OpenAI 互換サービスにはベース URL も指定します。対応する Chrome では、API キーが不要な「Chrome 内蔵 AI」も使えます。

AI はまずグループ化案を作ります。内容を確認し、不要なタブを案から除外したり、グループ名を変えたりしてから適用できます。「固定ルールとして保存」を選ぶと、完全な URL に一致するルールも保存します。初期設定では、すでにグループ化したタブを対象に含めません。

クラウド AI で実行すると、タブのタイトル、ドメイン、完全な URL を選んだプロバイダーに送ります。アクセス可能なページでは、メタデータ、Open Graph 情報、見出しなども送ります。本文全体は送りません。現在の実装では URL とページの補足情報の送信をオフにする設定はありません。

Chrome 内蔵 AI は、利用可能なモデルを端末内で実行します。初回はモデルの準備やダウンロードが必要になる場合があります。API キーはプロバイダーごとに端末内へ保存し、端末間では同期しません。詳しくは [プライバシーポリシー](./PRIVACY.ja.md) を参照してください。

## 言語設定

設定画面の `JA` で日本語、`EN` で英語、`中` で中国語、`A` でブラウザの言語に合わせます。自動選択では日本語・中国語を検出し、それ以外は英語を表示します。

日本語と英語はこのフォークで保守します。中国語は upstream の文言をそのまま取り込み、加筆・修正しません。フォーク独自の機能で中国語の原文がない項目は、英語を表示します。利用者が書いたルール名、パターン、プロンプト、ページタイトルは、言語を切り替えても翻訳しません。

詳しくは [言語の保守方針](./LOCALIZATION.ja.md) を参照してください。

## 開発と Chrome への読み込み

Node.js 24 と pnpm を用意して実行します。

```sh
pnpm install --frozen-lockfile
pnpm run dev
```

開発サーバーは React の画面開発に使えます。Chrome 拡張 API を使うには、ビルドした拡張を Chrome に読み込んでください。

```sh
pnpm run build
```

1. Chrome の `chrome://extensions` を開きます。
2. 「デベロッパー モード」を有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」を押します。
4. このプロジェクトの `dist` フォルダーを選びます。

変更後は再ビルドして、拡張機能の再読み込みボタンを押します。

## ショートカット

| 操作 | macOS | Windows / Linux |
| --- | --- | --- |
| TabWeave を開く | Command + B | Ctrl + B |
| タブを整理 | Option + Shift + G | Ctrl + Shift + G |
| 重複タブを閉じる | Option + Shift + D | Ctrl + Shift + X |
| コマンド検索を開く | Command + Shift + K | Ctrl + Shift + K |

Chrome や他の拡張と競合すると、ショートカットが未設定になることがあります。`chrome://extensions/shortcuts` で実際の割り当てを確認・変更できます。

## 端末間の同期

ルールは初期設定では端末内に保存し、「端末間でルールを同期」をオンにすると Chrome の同期ストレージを使います。一般設定は Chrome の同期ストレージ、AI の設定と API キーは端末内に保存します。Chrome 側の同期が有効な場合、同期ストレージのデータが Google アカウントを通じて共有されることがあります。

開発版の端末間同期には、同じ拡張 ID が必要です。「パッケージ化されていない拡張機能を読み込む」で導入した拡張は、端末ごとに ID が異なる場合があります。Chrome ウェブストアで公開された拡張には固定の ID があります。

開発版でルールを別の端末に移す場合は、インポート・エクスポートが確実です。インポートはルールをすべて置き換えるため、移行先の設定も先にエクスポートしてください。

## 検証

```sh
pnpm test
pnpm run lint
pnpm run build
```

開発サーバーで `/tests/popup-preview.html` を開くと、Chrome API を模した作業画面を確認できます。`?theme=light` でライトテーマ、`?lang=ja` で日本語になります。このプレビューは実際のブラウザーのタブを操作しません。

実際の Chrome でタイトル変更を検証するページは [tests/title-change.html](./tests/title-change.html)、ルール例は [tests/chrome-qa-rules.json](./tests/chrome-qa-rules.json) にあります。検証の詳細は [HANDOFF.md](./HANDOFF.md) を参照してください。

## プロジェクト構成

```text
src/
  background.ts          バックグラウンド処理
  popup.tsx              ポップアップとサイドパネル
  newtab.tsx             新しいタブのダッシュボード
  options.tsx            設定とルール編集
  command-content.ts    ページ上のコマンド検索
  components/ui.tsx     共通の画面部品
  lib/
    constants.ts        初期ルール、色、保存キー
    grouping.ts         ルール判定、グループ化、分類の見直し
    i18n.ts             日本語・英語の文言
    localized-errors.ts 利用者に表示するエラーの翻訳
    upstream-chinese.ts upstream から生成する中国語資源
    links.ts            リポジトリと拡張のリンク
    shortcuts.ts        OS ごとのショートカット表示
    storage.ts          Chrome ストレージへの保存・読み込み
    theme.ts            テーマの適用
    types.ts            共通の型定義
public/
  manifest.json         拡張機能の構成
  _locales/             Chrome に表示する拡張の説明とコマンド名
  icons/                拡張機能のアイコン
store-assets/           ストア掲載文、画像、素材一覧
```
