# TabWeave

Chrome のタブをルールに沿って整理する拡張機能です。URL、タイトル、ドメイン、正規表現を使ってグループ化できます。

[English documentation](./README.md) · [変更履歴](./CHANGELOG.md) · [プライバシーポリシー](./PRIVACY.md)

## 主な機能

- 複数条件を持つルールと、ドラッグによる優先順位の変更
- ポップアップとサイドパネルからの整理、グループの展開・折りたたみ、手動グループ化
- ウィンドウごとの自動整理 ON/OFF
- URL を変えずにタイトルが変更された場合の再分類
- 重複タブの削除、使っていないタブの休止
- AI によるグループ化案の確認と適用
- タブ・グループ・履歴・コマンドの検索
- タブの一時保管と指定時刻の再表示
- ウィンドウのスナップショット保存・復元
- ダーク・ライト・システム連動のテーマ、日本語・英語の UI

## 開発版を読み込む

Node.js 24 と pnpm を用意して、以下を実行します。

```sh
pnpm install --frozen-lockfile
pnpm run build
```

Chrome の `chrome://extensions` で「デベロッパー モード」を有効にし、「パッケージ化されていない拡張機能を読み込む」から `dist` を選択してください。変更後は再ビルドし、拡張の再読み込みボタンを押します。

## 言語設定

設定画面の `JA` で日本語、`EN` で英語、`A` でブラウザの言語に合わせます。自動選択では日本語ブラウザに日本語を表示し、それ以外は英語を表示します。

以前の中国語指定は日本語として読み込みます。変更されていない中国語の初期ルール名と初期 AI プロンプトも移行します。利用者が編集したルール名やプロンプトは維持します。

## ウィンドウごとの自動整理

「このウィンドウを自動整理」は初期状態で ON です。実際に自動整理を行うには、設定の「タブ作成時に整理」または「ページ更新時に整理」を有効にしてください。

OFF のウィンドウは、別のウィンドウからの自動走査でも既存のグループと展開状態を維持します。手動の整理は利用できます。ON に戻すと、自動整理が有効な場合はそのウィンドウだけを整理します。

ON/OFF は Chrome のセッション内で保持します。ブラウザの再起動や拡張の再読み込みでは初期状態に戻ります。

## 確認

```sh
pnpm test
pnpm run lint
pnpm run build
```

実際の Chrome でのタイトル変更用ページと検証用ルールは `tests/title-change.html` と `tests/chrome-qa-rules.json` にあります。検証の詳細は [HANDOFF.md](./HANDOFF.md) を参照してください。
